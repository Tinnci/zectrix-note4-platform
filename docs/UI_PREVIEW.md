# 界面方向与预览

| 界面 | 横屏 400×300 | 竖屏 300×400 |
| --- | --- | --- |
| 主页、工具、设置、阅读器、传书、口袋工具 | 原生布局，支持 0°/180° | 原生 300×400 布局（90°/270°），阅读器按 284×308 重新分页 |
| Lua 应用、USB 管理、连接、画廊、硬件测试 | 原生布局 | 暂未重排；仍以横屏显示，不能用旋转截图代替 |
| 本地日历锁屏 | 日期、月历、阅读进度 | 日期、月历、电量；独立布局 |
| HA 远程页面 | 双列，每列 4 个实体 | 单列，最多 8 个实体 |
| 手机图片锁屏 | 现有横屏格式 | 暂不支持 |

设置 → 屏幕方向：按 OK 依次切换横屏、竖屏、横屏倒置、竖屏倒置，并保存；锁屏方向独立切换横屏／竖屏，不改变应用方向。选中方向行时，底部提示「OK 旋转」。

应用与锁屏默认竖屏；已有方向偏好继续保留。CLI 使用 `display settings` 查询当前与已保存方向，`display orientation portrait` 和 `display lock-orientation portrait` 分别设置应用与锁屏方向；写入需要 `confirm <token>`，重启后生效。不带方向参数只查询，不写入。

预览中搜索 `-portrait` 查看竖屏页面，搜索 `settings-screen-direction` 或 `settings-lock-direction` 查看四种方向下的选中状态。

## 生成

在仓库根目录运行：

```sh
bun tools/ui-preview.ts
```

先执行真实 C++ 显示测试，导出英文、中文画布，再生成无凭据的 HA 示例。
结果位于 `build-ui-preview/index.html`：方向与语言筛选、1×/2×/3× 像素缩放，
可下载 SVG 和 PBM。`manifest.json` 标明来源、方向和原生尺寸。
输出目录被 Git 忽略，不提交截图。

更新 README／手册中的 PNG 截图：

```sh
bun tools/ui-preview.ts --docs
```

此选项需要 ImageMagick；普通预览不需要。截图保持原生尺寸并移除附带元数据。

`--reuse` 只重建索引和 HA 示例，复用已有固件 PBM；修改固件后应运行完整命令，
否则预览仍是旧画面。完整生成使用新的临时目录，测试失败保留旧索引；成功后仅将
不再生成的受管理图片移到 `build-ui-retired-*`，不删除用户自行放入的图片。
生成器不访问 HA，也不发布或刷写设备。

竖屏 PBM 每行有 4 个填充位；SVG 导出忽略这些位，保留最右、最下边缘像素。
测试包含四周、闰年和六周月历、未知时钟、配对码及横屏滚动列表。
竖屏每日一句保留完整上下两句；六周月份缩小行距，为两行文字留出空间。
横竖屏大日期使用原生 48 像素高数字，而不是四倍放大小号文字。
设置中的“日期字体”提供 A 衬线、B 几何、C 墨迹、D 波点、E 装饰艺术五种选择。
搜索 `font-a` 至 `font-e` 可查看每种字体 01–31 的中英文横竖屏锁屏。
源图与压缩占用见 [日期字体](design/date-digits/README.md)。
字形离线仿真与率失真报告工具见 [字体优化](FONT_OPTIMIZATION.md)；该报告的模拟反射图不是实机照片。
无线关闭微标使用居中的五像素对角线，端点不重复。
状态栏的 7×7 无线微标使用分离的上下箭头、圆环、圆点和故障标记；只更新形状，
不新增无线轮询或动画。
这些预览验证布局，不验证实体屏幕的残影、刷新延迟和按键手感。
