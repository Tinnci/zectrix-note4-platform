# 每日锁屏短句

内置 31 组中英双语短句，包含原来的 7 组及新增 24 组。内容为无署名的阅读与生活寄语，不冒用名人语录出处。
按本地公历日序选择，31 天循环；当天重启或唤醒不改变短句，无有效日期时使用第一组。
不联网取句子，不增加后台唤醒，也不持久化短句历史。

长度以实际绘制宽度为准，不只数 UTF-8 字节：

- 竖屏 300×400 日历：固定两行，每行最多 268px。
- 横屏 400×300 日历：两段以空格连接，完整句子最多 368px。
- 横屏格式化缓冲区为 96 字节，测试同时检查不会截断。
- 使用已有原生 16px 字形，不缩小字体或省略尾句来勉强容纳。

当前文案英文整句最多 45 个字符，中文单行最多 10 个字；这些只是编辑参考，实际像素检查仍是验证依据。

英文与中文都执行全周期的实际画布逐像素对照，检查两段完整出现。
中文精简固件的字形子集也已重新生成，避免新增汉字只在阅读器启用时才能显示。

修改位置：`components/note4_app/note4_sleep_cover.cc` 及 `include/note4_strings.inc`。
修改后运行：

```sh
uv run --no-project tools/generate-ui-font.py
tools/test-localization.sh
bun tools/ui-preview.ts --docs
```

在预览中搜索 `sleep-portrait-quote-` 或 `sleep-landscape-quote-`，可以查看全部短句的两种语言和布局。
