# Note4 Open Platform v1.2.0

Note4 is now a pocket reader and local file terminal with a bilingual Home,
retained reading progress, static sleep pictures and independently installable
small apps. This release packages the accumulated platform work into **Full**,
**Reader** and **Minimal** firmware for the black-and-white ESP32-S3 Note4.

**Start here:** [English handbook](https://github.com/Tinnci/zectrix-note4-platform/blob/v1.2.0/docs/HANDBOOK.md) · [中文使用手册](https://github.com/Tinnci/zectrix-note4-platform/blob/v1.2.0/docs/HANDBOOK_zh.md).
Offline HTML editions with embedded screenshots are included in the downloads.
This is an independent community project, not a manufacturer firmware release.

## Daily use

- **Read:** streamed UTF-8 TXT and basic unencrypted EPUB, CJK wrapping,
  16px/24px text, basic EPUB emphasis and eight recent bookmarks. Home's
  Continue Reading opens the last saved position.
- **Transfer:** USB Manager and a local Wi-Fi browser library for upload,
  export and deletion. Files stream into the existing storage transaction;
  duplicate names are preserved, interrupted uploads are cleaned up, and
  Wi-Fi stops after a completed session.
- **Navigate:** one three-button vocabulary across Home, private scenes and
  Apps. Hold OK returns; hold DOWN saves/exits and displays the sleep cover.
  The status bar shows time, radio activity and power observations.
- **Carry useful tools:** clock editing, a silent focus timer, month calendar,
  tally counter and static dashboard/landscape/privacy/phone-picture covers.
- **Install apps:** portable `.zapp` packages or Lua sources through USB or
  Wi-Fi. Calculator and Flashcards are separate downloads; runtime memory,
  instruction and display/input capability limits remain enforced.
- **Connect a companion:** Android source supports NFC-assisted enrollment,
  authorized BLE progress/time/weather sync and Wi-Fi book/picture transfer.
  Phone positions require explicit acceptance on Note4.

CrossPoint's streamed reading, local library and sleep workflow inform the
product. Flipper Zero's SceneManager/ViewPort inform deferred navigation and
display ownership. The Note4 implementations preserve the platform's single
foreground owner and existing driver/service boundaries.

## Install or upgrade

1. Download the chosen `zectrix-note4-v1.2.0-PROFILE.zip`, host-tools ZIP and
   `SHA256SUMS`. Compare the downloaded files with their checksum entries.
2. Back up existing content and identify the Note4 serial port. Extract the
   firmware ZIP into its own directory and run from there:

```bash
uvx --from esptool==4.11.0 esptool.py --chip esp32s3 --port PORT write_flash "@flash_args"
```

Replace `PORT` with the actual port and keep the quotes around `"@flash_args"`
in all shells, including Windows PowerShell. Keep power connected until completion.
The ZIP writes separate firmware/boot/table/OTA-selection segments. It preserves
NVS and content **only with the same installed partition layout**. Do not use
NOTE4C, erase the chip or merge erase-filled gaps. The separate `*-app.bin`
download is not a complete initial USB installation.

The optional **library-init ZIP replaces all books, apps and phone pictures**.
Use it once for an uninitialized Full/Reader library, or for an intentional
reset after exporting content. An ordinary firmware upgrade does not need it.
Mount failure never formats the partition automatically.

The download set also includes two standalone illustrated HTML handbooks,
portable uv-based USB/app tools, Calculator/Flashcards packages, source/build
manifests and license notices. The library initializer is always separate from
the firmware archives. The embedded firmware descriptor now uses `version.txt`
(`1.2.0`); manifests also record the source commit and any prerelease label.

## Engineering and validation

The release matrix builds Full/Minimal/Reader with ESP-IDF 5.5.2, reuses the
existing Host and Android checks, verifies worker download integrity, assembles
the complete set and verifies a downloaded draft before publication. The same
`bash tools/build-release.sh` produces local review artifacts. Existing public
releases are preserved on retries.

Local R2.1 profile builds produced:

| Metric | Full | Reader | Minimal |
| --- | ---: | ---: | ---: |
| Application image | 2,501,488 B | 1,483,040 B | 522,096 B |
| Free space in each 3 MiB application slot | 644,240 B | 1,662,688 B | 2,623,632 B |
| Static internal RAM | 201,815 B | 123,303 B | 108,323 B |

The package manifests report the exact sizes and provenance of the downloaded
candidate. Local verification on 2026-09-12 passed all **41 Host targets**,
**40 Android JVM tests** and the debug APK build, all three native firmware
builds, Full/Minimal comparison, ShellCheck and Actionlint. The fourteen-file
download set was extracted, compared against native image bytes/flash addresses
and checked against the independently assembled matrix set. Both example apps
were inspected with the extracted host tools. English/Chinese HTML was checked
at 1280px and 390px widths, including embedded images, language links and contents.

Connected-device Reader and Full flash/boot smoke checks passed with native
version `1.2.0`, 8 MiB octal PSRAM, the unchanged partitions, first Home frame,
boot confirmation and 11/15 application entries. The device finished on Full;
its existing content partition was preserved. A host-only USB fixture wait was
extended for intentionally fragmented I/O under host timer coalescing; its
disconnect, overflow and stale-command assertions remain unchanged.

The local artifacts are review candidates until committed source is available
to the remote workflow. GitHub publication is not represented by these local
checks; the workflow records the uploaded release when it runs.

## Known limits

- EPUB is text-oriented: no DRM, fixed layouts, embedded fonts, images or
  complex CSS. Fonts can lack glyphs. Progress is an approximate byte position.
- Content storage is 4 MiB shared by books/apps/pictures, with filesystem
  reserve. Reader lists the first 32 book names; transfer tools can page further.
- Sleep covers remain static. The focus timer is silent and does not wake the
  device. RTC power-off retention depends on the board's backup supply.
- The Android companion is distributed as source/debug build instructions,
  not a production-signed APK in this firmware set. Physical NFC/BLE and
  Android-version compatibility qualification remains separate from software tests.
- USB installation is provided. Trusted on-device OTA delivery/UX (#55),
  interrupted A/B update tests (#56), and physical display/sleep/RTC/current
  measurements (#57, #37/#38) remain open. A normal boot smoke is not evidence
  of interrupted updates, RF performance or multi-day battery life.

L1/S1/E1's software milestones are already closed. This release consolidates
their delivered functionality with E2 packaging and C2.1 software integration;
it does not close the remaining physical C1/D1 acceptance items.
