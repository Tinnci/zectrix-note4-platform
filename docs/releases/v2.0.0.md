# Note4 Platform 2.0.0 — development release notes

No tag or downloadable release is published by these source changes.

- Rename project-owned components, SDK namespaces, Kconfig/tool prefixes,
  firmware artifacts, CLI branding and Android package to Note4.
- Introduce SDK v2 (`note4::sdk::v2`) with no source compatibility aliases.
- Remove obsolete demo UI/Canvas forwarding headers; use canonical UI types.
- Separate allocation-free packed frame transforms from display ownership,
  retaining the existing SSD2683 waveform and power/error behavior.
- Allocate rotation scratch by format: 15KB mono, 30KB mono plus patch and
  60KB only for rotated grayscale. Preserve working state on allocation failure.
- Harden layout/grid/scrollbar edge cases and retain zero-allocation drawing.
- Split 47 host targets into five selectable groups with bounded parallelism,
  timing reports, isolated logs/builds, timeout and process-group cancellation.

Read [migration instructions](../NOTE4_MIGRATION.md) before updating. The new
Android application ID requires fresh enrollment; existing app-private data is
not automatically migrated. Firmware NVS/content layout and existing binary
packet formats remain unchanged. Do not erase NVS or initialize the library
as part of an ordinary naming upgrade. Physical display, sleep-current and
radio qualification still require device measurements.
